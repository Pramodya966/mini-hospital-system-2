# Mini Hospital Emergency Management System

A Java-based Mini Hospital Emergency Management System developed using Data Structures and Algorithms.

## Features

- Patient record management using Binary Search Tree (BST)
- Emergency patient management using Queue
- Treatment history management using Stack
- Patient visit history management using Singly Linked List
- Search, delete, enqueue, dequeue, push, pop and display operations

## Data Structures Used

### 1. Binary Search Tree (BST)
Used to store and manage patient records based on Patient ID.

### 2. Queue
Used to manage emergency patients using FIFO (First In, First Out).

### 3. Stack
Used to manage treatment history using LIFO (Last In, First Out).

### 4. Singly Linked List
Used to store and manage patient visit history.

## Project Files

- `Main.java` - Main program and demonstration
- `Patient.java` - Patient details
- `PatientBST.java` - Patient Binary Search Tree
- `EmergencyQueue.java` - Emergency Queue
- `Treatment.java` - Treatment details
- `Stack.java` - Treatment Stack
- `Visit.java` - Visit details
- `VisitLinkedList.java` - Patient Visit Linked List

## How to Run

1. Open the project in Visual Studio Code.
2. Compile the Java files.
3. Run `Main.java`.
4. The program demonstrates all implemented data structures and operations.
